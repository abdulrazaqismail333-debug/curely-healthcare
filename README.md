# 🏥 Curely Healthcare

A modern, responsive healthcare website built with **HTML, CSS, and JavaScript** to provide visitors with a clean and user-friendly healthcare experience.

🔗 **Live Website:** [Visit Curely Healthcare](https://abdulrazaqismail333-debug.github.io/curely-healthcare/)

## ✨ Features

- 📱 **Responsive Design** — adapts to different screen sizes.
- 🌙 **Dark Mode** — switch between light and dark themes, with the preference saved.
- 🧭 **Mobile Navigation** — a navigation menu designed for smaller screens.
- 📊 **Animated Statistics** — animated counters when the statistics section appears.
- 🎨 **Scroll Animations** — visual effects as sections enter the viewport.
- 🩺 **Healthcare Services** — sections introducing healthcare services and information.
- 👨‍⚕️ **Doctor Profiles** — a section showcasing healthcare professionals.
- 📅 **Appointment Form Demo** — a form interface with browser validation and a demo confirmation message.
- 📞 **Contact Information** — a section for visitors to find contact details.

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- Git and GitHub
- GitHub Pages

## 🚀 Getting Started

To run this project locally:

1. Clone the repository:

   ```bash
   git clone https://github.com/abdulrazaqismail333-debug/curely-healthcare.git
   ```

2. Open the project folder.

3. Open `index.html` in your browser.

No additional dependencies are required.

Curely Healthcare is a frontend demonstration project. The appointment form does not submit real bookings, and the website does not provide medical services or medical advice.
